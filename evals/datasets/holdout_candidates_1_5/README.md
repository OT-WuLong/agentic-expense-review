# 1.5.0 保留集候选（未冻结）

这里有 20 份不与 validation 共用票号、PDF 或申请编号的合成票据：餐饮 8、交通 8、住宿 4。`candidates.jsonl` 只包含申请输入和待审状态，**没有期望建议、规则结果或证据金标**；它们不是已完成的 test，也不能产生通过率。

在冻结前，由人逐条查看 PDF 与申请，填写建议、依据制度条款、附件锚点和规则期望；再补每条所需的预算、权限、查重等结构化事实。四条住宿还需要明确城市等级事实。随后单独生成正式 test 版本和 freeze 文件，且不要用这 20 条调参。此目录当前不得传给正式评测脚本冒充盲测。

三种 PDF 版式仍由项目自己的渲染器生成；这能检查部分布局差异，不能替代真实扫描件/OCR 数据。重建命令：`uv run python scripts/build_validation_expansion.py`。
